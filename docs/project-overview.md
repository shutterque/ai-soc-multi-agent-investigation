# Project Overview

## Project
AI-Powered Multi-Agent SOC Security Alert Investigation System

## Objective
To develop an AI-assisted security alert investigation system that collects,
correlates and analyses security evidence using multiple specialised agents,
while retaining human oversight for consequential decisions.

## Core Components
- SOC Analyst Web UI
- n8n Workflow Orchestration
- Multi-Agent Investigation Layer
- LLM / Model Layer
- Tools & Data Sources
- Governance & Guardrails

## Human-in-the-Loop
The system provides investigation findings, risk assessment and recommendations
to the SOC analyst. High-risk, uncertain or consequential actions require human
review and approval.

## Current Development Stage
Architecture and process design completed. Implementation and testing are in progress.
